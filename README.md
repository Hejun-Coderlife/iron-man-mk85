# Iron Man · Mark 85 (web)

A browser game built with three.js: walk, fly and fight as Iron Man Mark 85 in a desert village.

**Play:** https://hejun-coderlife.github.io/iron-man-mk85/

Controls: WASD move/fly · Space take off · C land · Shift boost · Mouse aim · LMB repulsor · RMB unibeam · Q forearm laser (hold) · E shoulder guns · F snap · M mute
